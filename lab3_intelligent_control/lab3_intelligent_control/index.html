Титульный лист

Самостоятельная работа студента (СРС 3) по дисциплинам «Технология программирования» и «FullStack разработка».

Тема: моделирование, прогнозирование и оценка технологического процесса приготовления лакокрасочных материалов на основе методов интеллектуального управления.

Цель и задачи

Цель: изучить принципы моделирования процесса приготовления ЛКМ, разработать модель, исследовать прогнозирование параметров и предложить систему интеллектуального управления для повышения качества продукции.

  1. Построить структурную схему процесса.
  2. Разработать математическую модель (тепловой баланс, вязкость).
  3. Обучить модель прогнозирования вязкости (линейная регрессия, случайный лес).
  4. Разработать алгоритм интеллектуального управления.
  5. Сравнить традиционное и интеллектуальное управление.

Описание процесса

Приготовление ЛКМ — многоэтапный процесс: дозирование компонентов, смешивание, диспергирование пигментов, регулирование вязкости, контроль температуры и проверка качества. Отклонения температуры, скорости перемешивания, времени и соотношения компонентов меняют вязкость, вызывают неоднородность и ухудшают свойства покрытия.

Структурная схема процесса

Математическая модель

Тепловой баланс

Cₚ·m·dT/dt = Pₕ − Qₗ

Cₚ = 1800 Дж/(кг·°C) — теплоёмкость; m = 100 кг — масса; Pₕ = P_нагр + 0,5·P_меш — тепловая мощность (нагреватель плюс доля мощности мешалки, P_меш = 0,03·n² Вт); Qₗ = k·(T − T_ср) — теплоотвод, k = 150 Вт/°C, T_ср ≈ 20 °C. Нагреватель: P_нагр = clip(2000·(T_уст − T), 0, 10000) Вт.

Вязкость μ = f(T, n, t, C)

μ = 900·e−0,035(T−25)·(C/50)²·(300/n)0,25·(1 + 0,5·e−t/8)

Физический смысл: вязкость падает с ростом T (экспоненциально), растёт с концентрацией твёрдой фазы C, снижается с ростом скорости сдвига (псевдопластичность, n^−0,25) и уменьшается по мере диспергирования (e^−t/8). Для определения коэффициентов нужны данные: вискозиметрия при разных T и C, замеры μ(t) при разных n, термограмма нагрева/остывания для оценки k и Cₚ·m.

Целевая вязкость: 700 мПа·с, допуск ±5 % (665–735 мПа·с).

Симуляция одной партии

Прогнозирование вязкости

Данные: 300 синтетических записей (T 20–50 °C, n 100–500 об/мин, t 2–20 мин, C 40–60 %) с мультипликативным шумом 4 %; выборка делится на обучающую (240) и тестовую (60).

Методы: (1) линейная регрессия по ln μ с признаками T, ln n, t, ln C (простая, интерпретируемая); (2) случайный лес — 40 деревьев глубиной 6, бутстрэп (улавливает нелинейность e^−t/8). Оба метода реализованы на JavaScript без библиотек; аналог на Python — файл viscosity_model.py. Точность оценивается на тесте: MAE, RMSE, R², MAPE.

Интеллектуальное управление

  1. Получение данных датчиков (T, n, C, мощность).
  2. Проверка корректности (диапазоны, скачки).
  3. Определение состояния процесса.
  4. Прогноз вязкости обученной моделью.
  5. Сравнение с целью 700 мПа·с ±5 %.
  6. Коррекция: T_уст += 25·e, n += 200·e (e — относительная ошибка μ̂), в пределах T 25–50 °C, n 100–500; мощность нагрева ≤ 10 кВт.
  7. Повторное измерение; завершение, когда прогноз в допуске две минуты подряд.

Традиционное: фиксированный режим T_уст = 35 °C, n = 300 об/мин, 30 мин. Интеллектуальное: режим корректируется по прогнозу. Возмущения: концентрация C ~ N(50; 2,5²) и температура среды (случайные для каждой партии).
