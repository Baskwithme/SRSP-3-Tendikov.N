# СРС 3. Моделирование приготовления ЛКМ с интеллектуальным управлением

Web-сайт-отчёт: схема процесса, модель, прогнозирование вязкости (регрессия и случайный лес), сравнение традиционного и интеллектуального управления, контрольные вопросы, выводы.

## Состав
- `index.html` — разметка и текст отчёта.
- `style.css` — оформление (адаптивное).
- `script.js` — модель, обучение моделей, управление, графики.
- `viscosity_model.py` — аналог практической части на Python (scikit-learn).
- `README.md` — эта инструкция.

## Запуск сайта
1. Распакуйте архив, файлы должны лежать в одной папке.
2. Откройте `index.html` двойным щелчком (Chrome, Edge, Firefox). Нужен интернет: Chart.js подключается с CDN (для офлайна скачайте `chart.umd.min.js` и замените адрес в первом теге `<script>`).

## Запуск Python-части
```
pip install numpy pandas scikit-learn
python viscosity_model.py
```
Скрипт создаёт `dataset.csv`, обучает обе модели и печатает метрики (MAE, RMSE, R², MAPE) и таблицу «факт/прогноз».

## Как пользоваться сайтом
Меню слева (на телефоне — сверху):
1. **Титул и цель** — титульный лист (впишите ФИО и группу в `index.html`), цель, задачи, таблица параметров.
2. **Схема процесса** — 7 этапов, входы, датчики, управление, выходы.
3. **Модель** — тепловой баланс и модель вязкости; ползунки T_уст, n, C меняют симуляцию партии (графики T(t) и μ(t), энергия, попадание в допуск 700±5 %).
4. **Прогнозирование** — анализ синтетических данных, метрики на тесте, график «факт–прогноз»; кнопка «Переобучить» меняет выборку.
5. **Управление** — алгоритм из 7 шагов; «Новая партия» сравнивает оба подхода на одной партии; таблица — результат по 200 партиям.
6. **Вопросы** — ответы на 10 контрольных вопросов (раскрываются по клику).
7. **Выводы** — выводы с числами из моделирования и список литературы.

## Важно
Все данные модельные (синтетические) и не подтверждают эффективность системы в реальном производстве. Задание 1 (Simulink) представлено структурной схемой на сайте; при необходимости модель можно повторить в Simulink по тем же уравнениям.
